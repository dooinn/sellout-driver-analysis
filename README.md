# 셀아웃 요인 기여도 분석 (Sell-out Driver Analysis)

> **"이번 주 셀아웃에 어떤 요인이 얼마나 영향을 줬나?"**를 설명하는 모델을 만들고, 비전문가도 이해할 수 있게 시각화하는 프로젝트입니다.
>
> 예: *"이번 주 1,310개 중 기본 수요 898개, 프로모션 +269개, 광고 +135개, 계절성 +73개, 더운 날씨 −68개"*

실제 데이터가 준비되기 전이라, **정답 효과를 미리 정해두고 만든 가상 주간 데이터(104주)**로 7가지 모델을 만들고 비교했습니다.
정답을 알고 있어서 **어느 모델이 효과를 정확히 찾아내는지 채점**할 수 있습니다.

## 3. 핵심 개념: 기여도 분해

판매량을 **여러 조각의 합**으로 봅니다.

> "평소라면 이만큼 팔렸을 텐데, 이번 주엔 할인 때문에 +130, 결품 때문에 −90…"

각 조각을 **요인의 기여도**라고 하고, 조각을 모두 더하면 모델 예측치가 됩니다.
이런 구조를 **가법(additive) 모델**이라고 하며, 마케팅 믹스 모델(MMM)의 기본 형태입니다.

접근법은 크게 두 가지입니다.

| 접근 | 방법 | 특징 |
|---|---|---|
| **가법 회귀 (MMM 방식)** | 선형 회귀, 릿지, GAM, 베이지안 MMM, 구조적 시계열 | 기여도 = 계수 × 값. **"그 요인이 없을 때" 대비** 효과라 직관적 |
| **트리 모델 + SHAP** | LightGBM, XGBoost | 상호작용·비선형을 자동 학습. SHAP 기여도는 **"평균적인 주" 대비**라 해석이 조금 다름 |

## 4. 요인별 설명

| 요인 | 설명 | 샘플 결과 |
|---|---|---|
| **기본 수요 (베이스)** | 아무 이벤트가 없는 평범한 주의 판매량. 브랜드 인지도·단골 고객처럼 꾸준히 사는 힘. **추세**(점점 잘 팔리는지)도 포함 | 약 860개에서 시작, 매주 +1.25개 |
| **계절성** | 매년 같은 시기에 반복되는 오르내림 (여름 아이스크림, 겨울 핫팩). 1년을 합치면 거의 0이지만 주별로는 크게 차이 남 | 연중 ±115개 |
| **할인** | 가격을 깎았을 때 늘어난 판매량. 할인율 1%p당 몇 개 | 1%p당 +13개 |
| **프로모션** | 할인과 별개의 행사 효과 (매대 진열, 1+1, 기획전) | 행사 주 +269개 |
| **광고** | ① **이월 효과(adstock)**: 오늘 본 광고가 다음 주 구매에도 영향 ② **포화 효과**: 광고비 2배 ≠ 판매 2배 | 이월률 60% |
| **공휴일** | 명절·연휴처럼 쇼핑이 많은 주의 추가 판매 | +168개 |
| **기온** | 날씨 민감 제품. 강수량·미세먼지 등으로 바꿀 수 있음 | 1°C당 −5개 (추울수록 잘 팔리는 설정) |
| **결품** | 수요가 없어서가 아니라 **팔 물건이 없어서** 줄어든 판매. 빠뜨리면 "이 주는 인기가 없었다"고 잘못 해석 | 결품 1일당 −91개 |
| **설명 안 된 부분 (오차)** | 위 요인으로 설명 못 한 나머지 (경쟁사 행사, SNS 화제, 우연). 특정 주에 크게 튀면 **모델에 없는 새 요인**이 있었다는 신호 | |

## 5. 모델 공식 (선형 회귀 = MMM 기본형)

```
셀아웃(t) = β0 + β1·t                          ← 기본 수요 (출발점 + 추세)
          + β2·sin(2πt/52) + β3·cos(2πt/52)   ← 계절성
          + β4·할인율(t)
          + β5·프로모션(t)                     ← 있으면 1, 없으면 0
          + β6·ln(1 + 광고스톡(t))             ← 광고
          + β7·공휴일(t)                       ← 있으면 1, 없으면 0
          + β8·(기온(t) − 평균기온)
          + β9·결품일수(t)
          + ε(t)                               ← 설명 안 된 부분

광고스톡(t) = 광고비(t) + λ · 광고스톡(t−1)
```

t는 몇 번째 주인지(0~103), β는 모델이 데이터에서 찾아낸 숫자입니다.

**각 항이 이렇게 생긴 이유**
- **sin + cos**: 52주 주기의 물결. 두 개를 섞으면 성수기가 언제든 맞출 수 있음
- **ln(1 + 광고스톡)**: 광고비가 커질수록 효과가 둔해지는 포화 효과
- **광고스톡**: 이번 주 광고비 + 지난주 효과의 λ(이월률)
- **기온 − 평균기온**: 평균 기온일 때 효과 0 → 더우면 마이너스, 추우면 플러스

**학습된 값 (샘플)**: β0=861, β1=1.25, β4=13.2, β5=269, β6=58.6, λ=0.6, β7=168, β8=−5.4, β9=−91

**β는 어떻게 찾나**: 실제와 예측 차이의 제곱합이 가장 작아지는 β를 고름(최소제곱법, OLS). λ는 0.0~0.9를 모두 시도해 가장 잘 맞는 값 선택.

**기여도 = β × 그 주의 값**. 예: 프로모션 기여 = 269 × 1 = +269, 기온 기여 = −5.4 × (25.8 − 13.2) ≈ −68. 모두 더하면 모델 예측치.

## 6. 대시보드 읽는 법

예시: 2025-04-28 주 (프로모션 진행, 평균기온 25.8°C, 실제 판매 1,310개)

**① 문장 요약**: 아무 이벤트가 없었다면 898개였을 주인데 1,310개가 팔렸다. 프로모션(+269), 광고(+135), 계절성(+73)이 끌어올렸고, 더운 날씨(−68)가 깎았다.

**② 색깔 비율 막대**: **판매를 올린 요인들만** 더한 값(898+73+269+135 = 1,375)을 100%로 놓고 나눈 비율.
기본 수요 65%, 프로모션 20%, 광고 10%, 계절성 5%. 판매를 줄인 요인(기온 −68)은 비율에서 빼고 따로 표시.

**③ 워터폴(계단식 막대)**: 위에서 아래로 읽음. 각 막대는 바로 위 막대가 끝난 지점에서 시작.

```
기본 수요 898 → 계절성 +73 → 971 → 할인 0 → 프로모션 +269 → 1,240
→ 광고 +135 → 1,375 → 공휴일 0 → 기온 −68 → 결품 0 → 모델 예측 1,307
                                                       실제 판매 1,310 (차이 3개 = 설명 안 된 부분)
```

즉, **막대는 모델 예측 개수**이고, 기본 수요에서 요인에 의해 더해지거나 깎이는 과정입니다. 실제 판매는 모델이 계산한 값이 아니라 실제로 팔린 숫자입니다.

**실무 해석**: "프로모션이 없었다면 약 1,040개 수준. 프로모션으로 약 270개, 광고로 약 135개를 더 팔았고, 더운 날씨가 아니었다면 70개 정도 더 팔 수 있었다."

## 7. 성능 지표와 과적합

| 지표 | 의미 |
|---|---|
| **R² (설명력)** | 판매 변동 중 모델이 설명한 비율. 0.96 = 96% |
| **MAPE (평균 오차율)** | 예측이 실제와 평균 몇 % 차이 나는지 |
| **새 데이터 MAPE** | 앞부분으로 학습 → 모델이 보지 못한 다음 8주 예측, 4번 반복 평균 (시계열 교차검증) |

**과적합**: 학습 기간 오차는 아주 작은데 새 데이터 오차가 크면, 이미 본 데이터를 외웠을 뿐 규칙을 배우지 못한 것.

## 8. 7개 모델 비교 결과

| 모델 | 학습 기간 MAPE | **새 데이터 MAPE** | **효과 추정 오차** (정답 대비) |
|---|---|---|---|
| **베이지안 MMM** | 2.8% | **3.0%** | **5.1%** |
| 선형 회귀 | 2.8% | 3.0% | 5.2% |
| 구조적 시계열 | 2.7% | 3.0% | 5.6% |
| 릿지 회귀 | 2.8% | 3.1% | 6.8% |
| GAM | 2.8% | 4.0% | 16.7% |
| LightGBM + SHAP | 0.9% | 6.2% | 27.7% |
| XGBoost + SHAP | 1.0% | 6.3% | 28.9% |

효과 추정 오차 = 할인·프로모션·광고·공휴일·기온·결품·계절성 7개 효과를 **모든 모델에 같은 정의로** 계산해 정답과 비교한 평균 오차율.

**주요 발견**
- **MMM과 선형 회귀가 공동 1위**. 숫자는 거의 같지만 MMM은 효과의 범위, 광고 포화, ROI까지 제공.
- **트리 모델(LightGBM·XGBoost)은 과적합**: 학습 오차 1% 미만, 새 데이터 6%대. 104주는 트리 모델에게 너무 적은 데이터. 기온 효과를 거의 못 찾음.
- **GAM은 기온과 계절을 혼동**: 둘 다 1년 주기로 움직여서 효과를 서로 나눠 가짐 → 둘 다 작게 추정.
- **구조적 시계열은 선형 회귀와 거의 동일**: 장점(변하는 기본 수요)이 이 데이터에선 쓰일 일이 없었음.

| 모델 | 추천 용도 |
|---|---|
| **베이지안 MMM** | 마케팅 예산·효과 의사결정 (**메인 추천**) |
| 선형 회귀 | 첫 분석, 빠른 설명 |
| 릿지 회귀 | 요인이 많거나 서로 겹칠 때 |
| GAM | 효과가 곡선 모양일 때 ("20°C까지 무관, 그 이상 급감") |
| LightGBM / XGBoost | 데이터가 많고(수천 행) 요인 간 상호작용이 있을 때 |
| 구조적 시계열 | 기본 수요가 들쭉날쭉할 때, 미래 예측이 주목적일 때 |

> ⚠️ **이 가상 데이터는 효과를 단순히 더하는 방식으로 만들어서, 같은 구조를 가정한 선형 회귀·MMM에 유리한 시험입니다.**
> 실제 데이터에 "공휴일 + 프로모션이면 효과가 두 배" 같은 상호작용이 있다면 GAM이나 트리 모델이 더 나을 수 있으니, 실제 데이터로 이 비교를 꼭 다시 돌려보세요.

## 9. 베이지안 MMM과 ROI

**선형 회귀와의 차이**
- 효과를 **범위(90% 신용구간)**로 추정: "프로모션 +268개 (249~286), 실제 효과가 이 범위에 있을 확률 90%"
- **상식을 사전분포로 반영**: 할인·프로모션·광고·공휴일 ≥ 0, 결품 ≤ 0 → 데이터가 적어도 엉뚱한 부호가 안 나옴
- 광고 **이월률과 포화 정도를 직접 학습** → 광고비 반응곡선

**정답 대비 결과**: 7개 효과 중 6개가 90% 범위 안. 광고 이월률만 66%(54~76%)로 정답 50%보다 약간 높음 (광고는 분리가 가장 어려운 요인).

**광고 포화**: 주평균 9.3백만원 지출 시 1백만원당 평균 약 16개를 더 팔았지만, **여기서 1백만원을 더 쓰면 추가 판매는 약 6개뿐**.

**ROI** = (늘어난 판매로 번 이익 − 쓴 비용) ÷ 쓴 비용. *예시 가정값: 판매가 20만원, 개당 이익 6만원, 프로모션 1회 800만원*

| 활동 | ROI (90% 범위) | 판정 |
|---|---|---|
| 프로모션 | **+101%** (+87 ~ +115%) | 남는 장사 |
| 광고 | −16% (−45 ~ +16%) | 불확실. 추가 1백만원의 한계 ROI는 약 −65% → **증액 비추천** |
| 할인 | **−72%** (−74 ~ −69%) | 손해 |

- **할인이 손해인 이유**: 1%p당 이익 +79만원 vs 비용 주당 약 242만원. 원래 정가에 사려던 고객에게도 깎아주기 때문.
- **결품**으로 2년간 약 1.4억원의 이익을 놓침.
- 가정값은 예시이며, `dashboards/02_bayesian_mmm_roi.html`에서 실제 숫자를 입력하면 바로 재계산됩니다.

## 10. 트리 모델(XGBoost·LightGBM)에 대한 논의

XGBoost와 LightGBM은 같은 **그래디언트 부스팅 트리** 계열이라 결과도 거의 같았습니다.

| 모델 | 학습 MAPE | 새 데이터 MAPE | 효과 오차 |
|---|---|---|---|
| XGBoost 기본 | 1.0% | 6.4% | 28.9% |
| XGBoost 단조 제약 + 얕은 트리 | 2.5% | 6.1% | 28.8% |
| 하이브리드 (선형 추세 + XGBoost) | 2.6% | 5.6% | – |
| (참고) 선형 회귀 | 2.8% | 3.0% | 5.2% |

**트리 모델이 이 데이터에서 약한 이유**
- **추세를 이어가지 못함(외삽 불가)**: 본 적 있는 값 범위 안에서만 예측 → 판매가 오르는 추세면 미래를 낮게 잡음. 새 데이터 오차의 주원인.
- **드문 이벤트를 잘 못 배움**: 공휴일은 2년에 14주뿐 → 효과를 180이 아닌 약 105로 추정.
- **효과를 여러 변수에 흩어 놓음**: 기온 효과가 계절성 쪽으로 흡수되어 거의 0.

**살리는 방법**: 단조 제약(효과 방향 고정), 선형 회귀로 추세·계절을 먼저 빼는 **하이브리드**, 그리고 무엇보다 **매장별·지역별로 데이터를 늘리기**. 지금 같은 104행에서는 보조 도구(상호작용 탐지용)로 추천.

## 11. 시계열 기법에 대한 논의

**요인을 많이 넣기 힘든가? → 아니요.** SARIMAX, Prophet, 구조적 시계열 모두 외부 요인(`exog`)을 넣을 수 있습니다. 제약은 기법이 아니라 **데이터 양**입니다.

| 모델 | 새 데이터 MAPE | 할인 | 프로모션 | 공휴일 | 기온 | 결품 |
|---|---|---|---|---|---|---|
| 정답 | | +14 | +260 | +180 | −6 | −95 |
| 구조적 시계열 | 3.0% | +13 | +268 | +168 | −5.4 | −91 |
| SARIMAX (추세 + AR1 + 요인) | 3.0% | +13 | +280 | +178 | **−1.1** | −88 |

**주의할 점**
- **미래 값이 필요**: 다음 주 예측에 다음 주 프로모션 계획·기온 예보 등이 있어야 함.
- **설명력이 떨어질 수 있음**: SARIMAX의 관성(AR) 항·계절 항이 기온 효과를 가져가 −1.1로 작게 추정.
- **SARIMAX 수렴 확인**: 반복 횟수가 부족하면 수렴하지 못하고 전혀 다른 계수가 나옴(노트북은 `maxiter=2000`). 대화 중 처음 보고된 SARIMAX 새 데이터 오차 4.6%는 일부 학습 구간에서 수렴하지 않은 결과였고, 수렴시키면 3.0%입니다.
- **구조적 시계열**의 장점은 **기본 수요가 시간에 따라 자유롭게 변하는 것**을 허용하는 것. 경쟁사 진입·유통 채널 변화로 기본 수요가 들쭉날쭉한 실제 데이터에서 선형 회귀보다 확실히 나아짐.

> 선형 회귀와 MMM도 추세·계절성을 넣었기 때문에 이미 **"요인을 넣은 시계열 회귀"**의 일종입니다. 시계열 기법은 대체재라기보다, 기본 수요가 불안정하거나 미래 예측이 주목적일 때 쓰는 업그레이드입니다.

## 12. 요인을 늘리면 데이터가 얼마나 더 필요한가

**기본적으로 그렇습니다.** 흔한 경험칙은 **추정할 계수 하나당 관측치 10~20개**.
지금 모델은 계수 약 10개 → 104주로 충분. 요인을 20개로 늘리면 200~400주(4~8년치) 필요.

**주차 수만큼 중요한 것**
1. **요인이 얼마나 자주·다양하게 변했나**: 2년간 3번 한 행사는 1,000주가 있어도 효과를 정확히 알 수 없음. 사실상 **그 요인이 움직인 횟수**가 중요.
2. **요인끼리 따로 움직였나**: 광고와 프로모션을 항상 같이 했다면 데이터가 아무리 많아도 분리 불가.
3. **효과가 노이즈에 비해 큰가**: 판매가 주마다 ±50개 흔들리는데 효과가 +10개면 잡기 어려움.

**주차를 늘리기 어려울 때**
- **데이터 쪼개기** (가장 효과적): 주간 → 일간, 전국 → 매장별·지역별. 매장 50곳 × 104주 = 5,200행.
- **사전 지식 활용**: 베이지안 MMM에 "할인 효과는 보통 이 정도" 정보를 넣으면 적은 데이터로도 안정적.
- **요인 묶기**: TV·유튜브·인스타 광고를 "디지털 광고"로 합치기.
- **실험하기**: 일부 지역에서만 광고를 꺼보는 테스트(지역 실험) → 효과를 확실히 알고 모델에 반영.

> 데이터를 너무 오래전까지 늘리는 것도 주의. 5년 전과 지금은 시장·경쟁사·소비자가 달라서 오래된 데이터가 오히려 현재 효과를 흐릴 수 있습니다.

## 13. 주의사항

- **상관 ≠ 인과**: 프로모션을 성수기에만 했다면 계절 효과가 프로모션 효과로 섞여 과대평가될 수 있음.
- **같이 움직이는 요인**: 가능하면 따로 진행한 주가 있어야 효과를 분리할 수 있음.
- **신용구간의 전제**: MMM의 범위는 모델 구조가 맞다는 전제 아래의 범위. 빠진 요인이 있으면 범위 자체가 틀릴 수 있음.
- **가상 데이터의 한계**: 가법 구조로 만들어 선형 계열 모델에 유리. 실제 데이터로 비교를 다시 돌려야 함.
